# T2: Wirkt REVOKE in einer laufenden Sitzung sofort?

Aus `/home/nikita/docker/ba-test`. Zwei Terminals.

## Vorbereitung (Terminal B)

```bash
V=vektoren/offene-fragen
docker compose down -v && docker compose up -d --wait
docker compose exec -T pg-service psql -U ba_admin -d ba_test -f - < $V/setup.sql
```

## Sitzungen öffnen

Terminal A (Opfer, bleibt die ganze Zeit offen):
```bash
docker compose exec -e PGPASSWORD=alt pg-service psql -h ba-test-pg -U t_victim -d ba_test
```

Terminal B (Superuser, bleibt offen):
```bash
docker compose exec pg-service psql -U ba_admin -d ba_test
```

## Teil 1: außerhalb einer Transaktion

| Schritt | Terminal | Befehl | Erwartung |
|---|---|---|---|
| 1 | A | `\set VERBOSITY verbose` | keine Ausgabe |
| 2 | A | `SELECT version();` | Version notieren |
| 3 | A | `SELECT * FROM t_data;` | 1 Zeile |
| 4 | B | `REVOKE SELECT ON t_data FROM t_victim;` | REVOKE |
| 5 | A | `SELECT * FROM t_data;` | `ERROR: 42501: permission denied for table t_data` |

## Teil 2: innerhalb einer offenen Transaktion

| Schritt | Terminal | Befehl | Erwartung |
|---|---|---|---|
| 6 | B | `GRANT SELECT ON t_data TO t_victim;` | GRANT |
| 7 | A | `SELECT * FROM t_data;` | 1 Zeile |
| 8 | A | `BEGIN;` | BEGIN |
| 9 | A | `SELECT * FROM t_data;` | 1 Zeile |
| 10 | B | `REVOKE SELECT ON t_data FROM t_victim;` | REVOKE |
| 11 | A | `SELECT * FROM t_data;` | 1 Zeile oder 42501 |
| 12 | A | `COMMIT;` | COMMIT, wenn 11 gelang; ROLLBACK, wenn 11 scheiterte |
| 13 | A | `SELECT * FROM t_data;` | 42501 |

Schritt 11 entscheidet: 1 Zeile heißt, das Recht wird innerhalb einer
Transaktion nicht neu geprüft. 42501 heißt, die Prüfung erfolgt je
Anweisung, auch innerhalb einer Transaktion. Schritt 13 muss in
beiden Fällen scheitern.
