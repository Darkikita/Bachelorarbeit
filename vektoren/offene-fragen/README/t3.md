# T3: Darf eine CREATEROLE-Rolle ohne ADMIN OPTION eine vordefinierte Rolle vergeben?

Aus `/home/nikita/docker/ba-test`. Zwei Terminals.

## Vorbereitung (Terminal B)

```bash
V=vektoren/offene-fragen
docker compose down -v && docker compose up -d --wait
docker compose exec -T pg-service psql -U ba_admin -d ba_test -f - < $V/setup.sql
```

Aus der Ausgabe prüfen:
- `SELECT version();` notieren
- `pg_auth_members` für `t_creator`: keine Zeile
- `createrole_self_grant`: leer

## Sitzungen öffnen

Terminal A (Angreifer mit CREATEROLE, bleibt offen):
```bash
docker compose exec -e PGPASSWORD=test pg-service psql -h ba-test-pg -U t_creator -d ba_test
```

Terminal B (Superuser, bleibt offen):
```bash
docker compose exec pg-service psql -U ba_admin -d ba_test
```

## Ablauf

| Schritt | Terminal | Befehl | wenn GRANT-Referenz gilt | wenn Kap. 21.5 gilt |
|---|---|---|---|---|
| 1 | A | `\set VERBOSITY verbose` | keine Ausgabe | keine Ausgabe |
| 2 | A | `SELECT current_user;` | `t_creator` | `t_creator` |
| 3 | A | `GRANT pg_read_server_files TO t_creator;` | `42501: permission denied to grant role "pg_read_server_files"` | GRANT ROLE |
| 4 | A | `CREATE ROLE t_new LOGIN PASSWORD 'test';` | CREATE ROLE | CREATE ROLE |
| 5 | A | `GRANT pg_read_server_files TO t_new;` | derselbe Fehler wie 3 | GRANT ROLE |
| 6 | A | `GRANT t_new TO t_creator WITH SET TRUE, INHERIT TRUE;` | GRANT ROLE | GRANT ROLE |
| 7 | B | `SELECT roleid::regrole, member::regrole, admin_option, inherit_option, set_option FROM pg_auth_members WHERE member IN ('t_creator'::regrole, 't_new'::regrole);` | nur `t_new → t_creator` (aus 4) und `t_creator ∋ t_new` (aus 6) | zusätzlich `pg_read_server_files` für t_creator und t_new |

Schritt 6 ist die Kontrolle: Er muss in beiden Fällen gelingen, sonst
stimmt CREATEROLE selbst nicht. Schritt 7 zeigt, welche
Mitgliedschaften wirklich entstanden sind, unabhängig von den
Meldungen.

## Festhalten

Ausgaben von A und B nach `ergebnisse/t3.md`, je Schritt Befehl und
Ausgabe, Fehlermeldungen samt SQLSTATE und DETAIL-Zeile. Vorkontrolle
aus `setup.sql` dazu.
